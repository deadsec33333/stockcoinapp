# Stockcoin

This folder is ready for Vercel as is. The website is at the top level, so Vercel detects Next.js automatically.

- **Website** (this folder): deploy to Vercel. Only add the 4 environment variables from `.env.example`.
- **Bot** (`bot/` folder): runs separately on Railway/Render. See `bot/README.md`.
- `FRONTEND_SPEC.md`: design and data spec for the site.
- `SITE_README.md`: notes that came with the website code.
